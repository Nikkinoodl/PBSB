# An Eleventy Website (Source Code)

This repository contains the source code for my own Eleventy‑powered static website (https://portraitsbysimonbland.com) and is maintained as a template for anyone who may benefit from it.


## What This Project Is

This is a simple, fast, no‑database static site. All of the layouts, templates, and content live in the main repo folder and its sub-folders.

## Working With the Site

Instructions for running the site and for building/configuring something to meet your own needs are provided in a separate document.
